Política de Privacidad de Cinebox

Última actualización: 24 de mayo de 2024

Cinebox es una aplicación desarrollada como un cliente no oficial de Telegram. Esta política explica cómo se manejan tus datos.

1. Recopilación de Datos

Cinebox no recopila ni almacena ningún dato personal en servidores propios. La aplicación actúa exclusivamente como una interfaz (cliente) para los servicios de Telegram.

2. Uso de la API de Telegram

La aplicación utiliza la librería oficial TDLib de Telegram para permitir el acceso a tu contenido. Al iniciar sesión, te autenticas directamente con los servidores de Telegram. Tus credenciales (como el código de acceso o contraseña 2FA) se procesan localmente y se envían de forma cifrada a Telegram a través del protocolo MTProto.

3. Almacenamiento Local

Cinebox almacena datos localmente en tu dispositivo Android TV para mejorar la experiencia:

  • Sesión de Telegram: Tokens de acceso necesarios para mantener la sesión iniciada.
  • Caché de medios: Archivos temporales de video, audio e imágenes para una reproducción fluida.
  • Progreso de reproducción: Datos sobre qué videos has visto y en qué minuto te quedaste ("Seguir viendo").

Estos datos permanecen en el almacenamiento interno de la aplicación en tu dispositivo.

4. Servicios de Terceros

Opcionalmente, la aplicación utiliza el servicio AcoustID para identificar metadatos de música. Para esto, se envía una "huella digital" anónima del audio (no el archivo completo). No se envía información personal a este servicio.

5. Seguridad

Toda la comunicación entre la aplicación y la nube de Telegram está protegida por el cifrado de extremo a servidor de Telegram.

6. Contacto

Si tienes dudas sobre esta política, puedes contactar al desarrollador a través del repositorio oficial en GitHub.

Cinebox es una aplicación independiente y no está afiliada, asociada, autorizada, respaldada ni conectada oficialmente de ninguna manera con Telegram FZ-LLC.
