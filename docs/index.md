# Cinebox

**Biblioteca personal para Android TV / Google TV**

Cinebox es una aplicación nativa diseñada para llevar tu contenido de Telegram directamente a la pantalla grande. Utiliza Kotlin, Jetpack Compose for TV, TDLib y Media3 para ofrecer una experiencia fluida, similar a las plataformas de streaming modernas.

## 🚀 Características Principales

- **Integración con Telegram**: Acceso directo a tus "Mensajes guardados" y canales privados.
- **Interfaz Nativa para TV**: Diseñada específicamente para el control remoto (D-pad).
- **Streaming Inteligente**: Reproducción fluida mediante ventanas acotadas de TDLib y Media3.
- **Organización Automática**: Series agrupadas por hashtags y música con metadatos enriquecidos vía AcoustID.
- **Seguir Viendo**: Progreso persistente localmente por cuenta.
